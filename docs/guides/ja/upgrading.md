## バージョン 1 の中で更新する

今回のドキュメント更新はコメント、ガイド、サイトの案内を変え、SDK の公開動作は変えません。名前の付いた各エントリーから読み込んでください。バージョンごとの追加は[変更履歴](../../../CHANGELOG.md)にあります。以前の詳しい Markdown の説明もリンクから読めます。

## 他のキューブライブラリーから移る

状態の表し方を確認して変換します。Kyuubu はパーツの配列ではなく、U、R、F、D、L、B の順のステッカーを保存します。実際のサイズで記号を読み、再構成では全体の回転を保ちます。初心者の解法は最短とは限りません。直方体では普通のキューブの 4 分の 1 回転をそのまま使わず、断面の規則を確認します。

## 組み込み方を選ぶ

状態と記号には基本エンジン、ブラウザーの表示には CubeView、コンポーネントと ref には React、操作ボタン付きの再生には player、HTML タグには定義用エントリーを使います。直接作ったハンドルは外すときに片付けます。検索索引はサイトと一緒に端末で作られ、新しいホスト型サービスは使いません。

## リリース前に

新しく書いた日本語を確認し、インストールしたパッケージで API の例を確かめます。ローカルのドキュメント更新では公開、リポジトリーの設定変更、ソーシャル画像のアップロードは行いません。
